laura.models.\_generated module
-------------------------------

The Pydantic base classes generated from the LinkML ontology. This module is
regenerated by ``python laura/schema/generate_pydantic.py`` and must not be
edited by hand; every class in it is wrapped by a hand-written class in one of
the modules above, which is what user code should import. It is listed here for
reference only -- see :doc:`Architecture/element-hierarchy`.
